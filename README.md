# FIT BOX Web v6.4

포장공간비율 계산, 제품 배치, 상자 규격 추천, 포장재 재질·구조 간이평가를 제공하는 공개 웹 버전입니다.

## v6.4 주요 기능

- 현재 설계값과 판정 결과를 3페이지 PDF 결과보고서로 생성
- 탑뷰 및 3D 배치 이미지 포함
- 제품별 치수·수량·완충재와 계산 근거 정리
- 우체국 상자 추천과 포장재 재질·구조 간이평가 결과 포함

챗봇은 브라우저 내 안내서 검색 방식으로 작동하며 별도의 API 키가 필요하지 않습니다. 간이평가 결과는 참고용이므로 실제 신고나 등급 표시 전 공식 포털에서 최종 확인해야 합니다.

## 보안

저장소에는 API 키, `.env`, 관리자 인증정보 또는 로컬 서버 파일을 포함하지 않습니다.
